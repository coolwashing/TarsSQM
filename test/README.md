## 🚀 如何在页面上手动测试

1. 打开浏览器访问系统的任意清单页面（例如 **供应商清单** 或 **零件清单**）；
2. 在搜索卡片右侧的工具栏区域，点击 **`批量导入`**（或点击旁边的下载图标直接下载模板）；
3. **测试合规导入**：
   - 拖拽或选取 `d:\AIAPP\Tars\test\01_供应商主数据_全部合规.xlsx`；
   - 系统将自动进行 5 层纵深校验，展示全部合规报告；
   - 点击 **`确认批量导入`**，数据即刻持久化入库，表格自动刷新。
4. **测试异常拦截与纠错报告**：
   - 拖拽或选取 `d:\AIAPP\Tars\test\02_供应商主数据_包含多种异常.xlsx`；
   - 观察校验结果报告：系统将精准标识出 **文件内编码重复**、**准入状态不在枚举值范围内**、**必填项为空** 等行级具体错误；
   - 支持切换 `[全部行]` / `[仅看异常]` 过滤器查看详情。

## 🧪 如何执行自动化测试脚本

在命令行执行：
```powershell
cd d:\AIAPP\Tars\test
python generate_and_test.py
```
该脚本会自动调用后端：
1. 测试并生成全系统 6 大模块的 Excel 规范模板；
2. 上传合规与异常文件，断言行级校验拦截结果；
3. 执行原子事务入库并验证数据库持久化。
