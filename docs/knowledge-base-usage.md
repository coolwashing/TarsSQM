# 知识库使用说明

## 原文件

打开目标目录，点击“上传文件”，或把文件拖入内容区，确认上传。单个文件上限 50 MB。

Excel、PDF、Word 和文本保留原件，数据库只保存目录、关联元数据及提取文本摘要。正文索引位于 `storage/kb-index`。双击附件或点击属性栏中的“下载原件”即可获取文件；右键可独立复制、移动或删除。目录删除会清理其中的附件和索引。

目前提取 xlsx/xlsm、文字型 PDF、docx、txt/md/csv。旧版 xls、扫描 PDF、加密文件等保留原件，但可能无法提取正文；属性栏会说明原因，可在补齐依赖或转换格式后重新索引。为保证轻量，首版每份文件最多索引 800 个片段，Excel 每表读取前 50000 行、前 200 列，PDF 前 300 页；超出部分仍在原件中。

PDF 提取依赖 `pypdf`。启动脚本会检查依赖并按 `backend/requirements.txt` 安装。若当前运行进程尚未安装依赖，可在停止后端后重新运行 `start_backend.bat`，然后对之前上传的 PDF 点击“重新索引”。

## 搜索与 AI

顶部搜索覆盖在线正文与附件提取文本；结果显示命中内容、工作表/行号或 PDF 页码。首版是关键词分块检索，不需要向量模型或模型 API Key。RAG 把检索片段及出处加入 AI 任务；未检索到资料时不应编造依据。

AI 面板提供“知识问答”和“文档编辑”，可选择全库检索或当前目录。在线编辑器中的选区、信标作为额外参考。首版确认按钮明确作用于“追加到文末”或“替换全文”，不宣称自动精确替换信标段落。

### 无 API Key：交给 Codex / IDE

1. 填写需求，点击“复制任务给 IDE”。
2. 在打开同一项目、拥有本地文件读写权限的 Codex/IDE 中粘贴并发送任务。
3. IDE 按任务要求写入 `storage/kb-ai-tasks/<任务编号>/result.json`。
4. 页面每约 2 秒自动检查结果，无需把生成内容粘回网页。关闭面板或刷新后，再打开相同文档/目录的面板可恢复任务。
5. 核对来源及原文/结果对照；确认追加、替换或另存为文档。生成和预览不会自动写入原文；原文发生变化时会阻止旧任务覆盖。

本地回传要求后端和 IDE 能访问同一个任务目录；远程后端或纯聊天窗口不具备这一条件，需要另外配置共享目录或正式连接器。任务文件、索引和原件应随存储目录备份，均不纳入 Git。此实现沿用项目现有的本地开发服务访问方式，不是面向公网的多用户授权方案。

### 可选：后端模型 API

管理员在后端环境变量中配置 `AI_API_BASE`、`AI_MODEL`、`AI_API_KEY`，然后选择“使用后端配置的模型”。接口按 OpenAI 兼容的 Chat Completions 调用，模型必须支持该协议。密钥不下发到前端，也不写入任务文件。连接失败会展示失败状态，不用模板内容冒充真实生成。

不要继续使用已经贴进聊天的密钥；应先在提供方撤销并换新。本轮开发没有保存或测试那串密钥，也没有调用付费模型进行生成测试。

## 后续工具

FMEA、CP、特性清单等以后独立保存结构化业务数据，复用目录关联与附件引擎，并将业务内容导出为带来源的检索文本。当前不增加审批、受控流程、向量数据库或在线 Excel 编辑器。

## 验证

- `npm.cmd run build`（在 frontend 中）
- `node --test test/kb_moves.mjs test/kb_workspace.mjs test/kb_ai_panel.mjs`（在项目根目录中，接口测试需后端运行）

接口测试只创建带 `__TEST_` 标记的临时数据，完成后清理自己的记录、文件、索引和任务。PDF 原件测试与正文提取测试分开报告，缺少解析依赖时不声称提取已验证。
