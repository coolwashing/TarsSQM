# 知识库开发计划

## 实施状态

- 已实现附件目录、关键词分块检索、AI 任务文件回传、结果对照、人工确认及原文冲突检查。
- 前端构建通过；5 项回归测试通过（3 项面板生命周期测试、移动接口测试、附件与任务集成测试），临时数据已清理。
- PDF 原件存储/下载已验证；PDF 正文提取的依赖安装被自动审批服务的默认模型分组配置错误阻塞，当前尚未验证。
- API 模式已接入后端配置，但没有使用真实付费模型或聊天中提供的密钥进行生成联调。
- 本轮通过构建和组件逻辑测试验证前端；尚未完成浏览器中的视觉和交互验收。

## 本轮交付

1. **附件目录**：文件上传、拖入、下载、目录内复制、移动、删除。复用 `sys_attachment` 保存元数据，原文件放 `storage/files`；知识库节点以 `biz_type=FILE` 关联附件，不把二进制原件存数据库。
2. **搜索与 RAG**：提取 Excel、PDF、Word、文本正文，建立带工作表/行号/页码的本地分块索引。搜索与 AI 共用检索结果，保留出处。首版采用关键词分块排序，不伪装成向量检索；扫描 PDF、旧版 Excel 等无法提取时明确提示，原件仍可下载。
3. **AI 问答与编辑**：统一简洁面板，支持“知识问答 / 文档编辑”。默认复制任务给 IDE，IDE 把结果写入约定文件，页面轮询后自动预览，不再要求粘回内容。可选模型 API 使用后端既有 `AI_API_BASE`、`AI_MODEL`、`AI_API_KEY` 配置；不保存用户已公开的密钥。
4. **人工确认**：生成不会自动修改正文。编辑结果先对照原文，再确认追加或替换全文；正文发生变化则阻止覆盖。问答结果可另存为在线文档。

## 界面约定

- 保留目录、内容区、属性栏；增加一个“上传文件”入口，支持内容区拖入。
- 附件显示文件名和图标，下载与索引状态放属性栏，不强制在线预览。
- 搜索结果显示命中片段与来源；AI 面板只保留需求、生成方式、状态、参考资料和结果确认。
- 不新增受控、审批、复杂版本流程，不新增在线 Excel 编辑器。

## 数据与任务

- 在线正文继续使用 `sqm_kb_doc`；附件节点通过 `biz_id` 关联 `sys_attachment`。
- 分块索引位于 `storage/kb-index`，可重建；不作为原文件唯一副本。
- AI 任务位于 `storage/kb-ai-tasks/<任务编号>`，包含请求、提示词和结果文件。目录不纳入 Git、不挂载公开静态目录。
- 每个任务绑定原文快照；应用时检查原文是否改变。任务处理状态持久化，刷新页面可继续等待。
- IDE 必须有权限读写任务目录；纯聊天窗口不具备自动回传能力。前端轮询只传输状态，不提供模型计算。

## 验收

- Excel/PDF 上传后可下载原件；索引结果能显示工作表/行号或页码。
- 附件可随目录移动、独立复制；删除临时测试目录后文件和索引同步清理。
- 检索可命中在线正文及附件，AI 任务包含真实引用，无结果时明确表示未找到。
- 写入任务结果文件后，无需人工粘回页面即可取得预览；确认前正文不变。
- 追加、替换、新建、正文冲突、任务恢复、异常结果、API 失败有明确反馈。
- 前端构建、现有移动回归及新增临时数据集成测试通过。

## 后续扩展

FMEA、CP、特性清单和检验指导书以后作为独立业务工具开发，保存结构化数据，通过知识库节点/附件关联；将结构化内容导出为带来源的检索文本，复用本轮搜索和 AI 任务接口。向量检索、OCR 仅在实际需要时追加。
