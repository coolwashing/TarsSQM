# SQM 供应商与质量管理系统 - 独立便携运行与单文件打包方案

本方案专为**「零环境依赖、单文件分发、开箱即用」**设计。您只需要将生成的单个 `.exe` 文件复制到任何全新的 Windows 电脑（无需安装 Python、Node.js、MySQL 等任何环境），双击即可运行！

---

## 📁 目录结构说明

```
d:\AIAPP\Tars\package\
├── launcher.py             # Python Tkinter 桌面控制台（启停服务、一键打开浏览器、参数配置、实时日志）
├── server_app.py           # 整合后端：FastAPI 服务 + Vue 前端静态托管 + SQLite/MySQL 自动兼容
├── build_package.py        # 自动化打包脚本（前端构建 -> PyInstaller 单文件打包 -> 生成便携 Zip）
├── build_package.bat       # Windows 一键执行打包脚本（双击运行）
└── output\                 # 打包产物输出目录
    ├── SQM质量管理系统.exe   # ★ 核心独立单文件（可直接复制分发）
    ├── SQM质量管理系统_开箱即用版.zip # 绿色便携压缩包
    └── config.ini.example  # 参数配置模板
```

---

## 🚀 如何生成打包文件？

在当前电脑上，您可以通过以下任一方式执行打包：

1. **方式一（最简单）**：
   - 直接双击运行 `d:\AIAPP\Tars\package\build_package.bat`。

2. **方式二（命令行）**：
   ```bash
   cd d:\AIAPP\Tars\package
   python build_package.py
   ```

打包脚本会自动完成：
- 前端 `npm run build`，编译包含最新 UI 的单页应用；
- PyInstaller 将 Python 解释器、FastAPI 后端、Vue 前端静态资源、数据库引擎全部打入一个 `.exe`；
- 输出独立单文件 `package\output\SQM质量管理系统.exe`。

---

## 💻 复制到其他电脑如何使用？

1. **只需要复制 1 个文件**：
   - 将 `package\output\SQM质量管理系统.exe` 复制到目标电脑的任意目录（如桌面或 D 盘）。
2. **双击启动**：
   - 双击 `SQM质量管理系统.exe`，将弹出图形化管理控制台。
3. **点击「🚀 启动系统」**：
   - 程序将自动初始化内置数据库，并在 1~2 秒内自动调起系统默认浏览器进入工作台！
4. **数据存储位置**：
   - 程序运行时，会自动在 `.exe` 同级目录下生成：
     - `data/sqm_data.db`（SQLite 数据库文件，随系统移动不丢失）
     - `storage/files/`（附件上传目录）
     - `config.ini`（系统配置文件）

## ⚙️ Python 桌面控制台功能特色

1. **一键启停与联动**：
   - **「🚀 启动系统」**：启动后台服务并自动调起浏览器。
   - **「🌐 打开工作台」**：随时再次打开浏览器进入页面。
   - **「🛑 停止服务」**：平稳终止服务。
2. **可视化配置（点击「⚙️ 系统配置」）**：
   - **服务端口**：默认为 `8010`，如有冲突可在界面随时修改（如 `8020`）。
   - **网络共享**：勾选「开启局域网共享」后，同一局域网下的其他手机或电脑也能通过 `http://本机IP:8010` 访问！
   - **数据库切换**：
     - **单机便携模式（SQLite）**：默认选项，无需安装任何数据库软件，开箱即用。
     - **企业远程模式（MySQL）**：提供 Host、端口、账号、密码设置，并附带「测试连接」按钮，方便连接公司内部数据库。
3. **实时日志监视**：
   - 控制台内嵌黑客风格深色终端窗口，所有接口请求、状态变化、启动信息实时滚动展示。
